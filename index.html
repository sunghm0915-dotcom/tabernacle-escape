Project TABERNACLE — QR 페이지 모음

리허설·제작 확인용 목록입니다. 실제 QR 코드는 이 페이지가 아니라, 아래 각 페이지의 최종 배포 주소로 만들어서 현장에 붙입니다.
■ 처음 보는 QR눈에 보이게 부착 · □ 숨은 QR막힌 조만 찾는 힌트 · ◆ 안내 QR완료 확인 + 다음 장소 · ▲ 문제 QR미션 문제 보기
현재 4개 조 기준으로 구성했습니다 (②③④ 안뜰 힌트 페이지는 조마다 1부씩 인쇄).
모든 ▲ 문제 QR 페이지는 문제를 바로 보여주지 않고, 짧은 이야기(스토리) → "▶ 임무 확인하기" 버튼(페이지마다 다른 전환 애니메이션) → 문제 순서로 진행됩니다. 그리고 "풀고 나면 어디로 가야 하는지"는 이 페이지들에 절대 나오지 않습니다 — 다음 행동은 실제로 미션을 완료해야만 열리는 별도의 QR·상자·쪽지에서만 확인할 수 있습니다 (자세한 내용은 README 참고).
