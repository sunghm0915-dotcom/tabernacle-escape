# 성막 방탈출 — QR 웹사이트

코딩을 몰라도 그대로 따라 하면 배포까지 끝나도록, 최대한 쉬운 방법(웹 화면에서 마우스로 클릭·드래그)만 썼습니다. 터미널·git 명령어는 하나도 필요 없습니다.

---

## 0. 이게 뭔가요

QR이 가리키는 웹페이지 16개입니다(그중 일부는 조마다 다른 문제/힌트를 보여줘야 해서 조별로 다른 주소로 QR을 여러 장 인쇄합니다 — **현재 4개 조 기준**). 영상 없이 텍스트·애니메이션만으로도 완결된 연출이 되도록 만들었고, 나중에 영상 파일이 생기면 그 파일을 끼워 넣기만 하면 자동으로 영상이 재생되는 구조입니다. 즉 지금 당장 이 상태로 QR을 붙여도 되고, 영상이 완성되면 그때 추가해도 됩니다.

### 조마다 다른 QR 만들기 (`?team=` 주소)

`m3`, `m4a`, `m4b`, `m7` 네 페이지는 조마다 실제 수학 문제가 다릅니다. 파일은 하나지만, 주소 끝에 `?team=조번호`를 붙이면 그 조의 문제만 보여줍니다. 즉 QR 코드 생성 사이트에 아래처럼 4개의 서로 다른 주소를 각각 넣어 4장을 만들면 됩니다.

```
https://아이디.github.io/tabernacle-escape/m3.html?team=1
https://아이디.github.io/tabernacle-escape/m3.html?team=2
https://아이디.github.io/tabernacle-escape/m3.html?team=3
https://아이디.github.io/tabernacle-escape/m3.html?team=4
```

`m4a.html`, `m4b.html`, `m7.html`도 똑같은 방식으로 `?team=1`~`4`를 붙여 4장씩 만들어주세요. (주소 뒤에 `?team=조번호`를 안 붙이고 그냥 열면, 리허설용으로 조 번호를 고르는 화면이 나옵니다.)

### 스토리 → 문제 순서로 보여주기

`m1`, `m2`, `m3`, `m4a`, `m4b`, `m5`, `m6`, `m7` — 이 8개 페이지는 전부 같은 구조입니다.

1. 화면을 열면 먼저 **짧은 이야기(스토리)** 가 보입니다. (예: "설계도가 완성이 되었다. 그런데 문제가 생겼다…")
2. 그 아래 **"▶ 임무 확인하기"** 버튼을 누르면 이야기가 사라지고, 실제 미션 안내나 수학 문제가 나타납니다.

문제부터 툭 튀어나오지 않고, RPG 게임 퀘스트처럼 "왜 이 문제를 풀어야 하는지" 먼저 보여준 다음 문제로 들어가는 구조입니다. 이야기 문구를 바꾸고 싶으면 해당 파일을 열어(✏️ Edit) `<div class="story-card" id="storyBox">` 안의 `<p>` 문장들을 원하는 대로 고치면 됩니다.

전환할 때는 그냥 화면이 뚝 바뀌지 않고, 페이지마다 다른 애니메이션(디졸브·솟아오르기·확대·와이프)으로 부드럽게 넘어갑니다.

### 미션 시작 화면 ≠ 미션 완료 화면 (일부러 나눴습니다)

**모든 문제 QR 페이지는 "이 문제를 풀어라"까지만 보여주고, "풀고 나면 어디로 가라"는 절대 보여주지 않습니다.** 다음 행동은 문제를 실제로 다 풀고 자물쇠를 열거나 상자를 찾아야만 볼 수 있는, 완전히 다른 QR·쪽지에서 나옵니다.

| 미션 | 문제를 보는 곳 | 풀고 난 뒤 다음 행동을 보는 곳 |
|---|---|---|
| M1 | `m1.html` (진짜 조각 7개를 찾으라, 그 이상은 알려주지 않음) | `m1-clear.html` — 찾아낸 **진짜 조각 뒷면**에만 작게 표시된 QR |
| M2 | `m2.html` (칠교로 조립하라) | 없음 — 완성한 설계도 자체가 훼손되어 있어서, 조립을 마치는 순간 물리적으로 바로 보입니다 |
| M3 | `m3.html?team=N` (닮음 문제) | 없음 — 자물쇠를 열면 상자 안 내용물(성막 기구)이 곧 결과이자 다음 행동입니다 |
| M4 | `m4a.html` + `m4b.html` (숫자 두 개를 구하는 문제만) | `m4-next.html` — 기구 배치 키트 상자 **맨 밑바닥**에만 있는 QR (출애굽기 40:6 확인 + "3층으로 가라") |
| M5 | `m5.html` (세 기구를 배치하는 문제만) | `twist.html` — 세 기구를 **실제로 정위치에 배치해야만** 나타나는 숨은 QR ("언약궤가 없다, 1층으로") |
| M6 | `m6.html` (기본 도형 문제만) | 없음 — 상자를 열면 나오는 종이 쪽지("4층으로 가시오")가 다음 행동입니다 (QR 아님) |
| M7 | `m7.html?team=N` (삼각비 문제만) | 없음 — 언약궤를 실제로 찾으면 나오는 종이 쪽지("3층 지성소로 가시오")가 다음 행동입니다 |

즉 어떤 미션은 "완료 후 QR"이 따로 있고, 어떤 미션은 상자 내용물이나 종이 쪽지처럼 **물리적인 결과물 자체**가 다음 행동을 알려줍니다 — 그래서 표에 "없음"이라고 적힌 칸은 빠뜨린 게 아니라, 원래부터 화면이 아니라 실물로 보여주도록 설계된 부분입니다.

**QR이 아닌 종이 쪽지로 처리한 지점 (참고)**: M6 상자를 열면 나오는 "4층으로 가시오"와, M7에서 언약궤를 찾은 뒤의 "3층 지성소로 가시오"는 QR 대신 종이 카드로 통일했습니다. 짧은 한 줄 안내에 굳이 폰을 꺼내게 하지 않기 위해서입니다 (영상·연출이 있는 순간에만 QR을 쓰는 원칙 유지).

**직접 채워 넣으셔야 하는 부분**: `m4-next.html`(출애굽기 40:6 실제 본문), `ending.html`(마무리 인물 멘트, 저녁 프로그램 안내), `m6.html`(4문제의 답을 4자리 비밀번호로 조합하는 정확한 방법)에는 이탤릭체로 "여기에 ~ 적어주세요"라고 표시된 자리가 있습니다. 성경 본문은 교회에서 쓰는 번역본을 그대로, 마무리 멘트는 신학적으로 정확한 문구를, M6 비밀번호 조합 방법은 M6 담당 선생님이 직접 채워주시는 게 안전합니다 — PDF 문제지에 조합 방법이 나와 있지 않아서 제가 임의로 만들지 않았습니다.

**M4 문제(1)·(2)에 "답이 40/6이 나오게"라는 문구가 안 보이는 것은 실수가 아닙니다**: 원본 문제지에는 "답이 40 나오게", "답이 6 나오게"라고 적혀 있었지만, 이걸 그대로 보여주면 조원들이 계산도 하기 전에 답을 알게 되어버립니다. 그래서 웹페이지에는 이 문구를 빼고 문제만 보여주도록 만들었습니다. 실제로 조마다 다른 문제를 풀어도 계산 결과는 항상 40(M4 문제1)과 6(M4 문제2)이 나오도록 원본 문제가 이미 설계되어 있습니다.

## 1. 배포하기 (깃허브 페이지, 전부 마우스 클릭으로)

1. [github.com](https://github.com) 접속 → 계정이 없으면 무료 가입.
2. 오른쪽 위 **+** 버튼 → **New repository** 클릭.
3. Repository name에 `tabernacle-escape` 같은 이름 입력 → **Public** 선택 → 그대로 **Create repository**.
4. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭 (또는 **Add file → Upload files**).
5. 이 폴더 안의 파일·폴더를 **전부 통째로** 끌어다(드래그 앤 드롭) 브라우저 창에 놓습니다. (`index.html`, `brief.html` 등 html 파일들 + `assets` 폴더 전체 + 이 `README.md`) — 크롬 브라우저면 폴더째로 끌어놔도 폴더 구조가 그대로 유지됩니다.
6. 아래 **Commit changes** 버튼 클릭 → 업로드 완료.
7. 저장소 상단 메뉴 **Settings** 클릭 → 왼쪽 메뉴 **Pages** 클릭.
8. **Build and deployment → Source**를 **Deploy from a branch**로 두고, **Branch**를 `main` / `(root)`로 선택 → **Save**.
9. 1~2분 기다리면 같은 화면 위쪽에 **주소(예: `https://아이디.github.io/tabernacle-escape/`)** 가 표시됩니다. 이게 사이트 주소입니다.

이후 각 QR이 가리킬 최종 주소는 예를 들어 다음과 같습니다.

```
https://아이디.github.io/tabernacle-escape/brief.html
https://아이디.github.io/tabernacle-escape/entrance.html
https://아이디.github.io/tabernacle-escape/twist.html
...
```

## 2. QR 코드 이미지 만들기

배포된 주소가 나오면, 무료 QR 생성 사이트(예: [me-qr.com](https://www.me-qr.com), 네이버에 "QR코드 생성기" 검색)에 위 주소를 하나씩 붙여넣고 PNG로 다운로드 → 인쇄하면 됩니다. 위 표에 있는 주소마다 QR을 하나씩 만들면 되고, `?team=1`~`4`가 붙는 페이지(M3·M4(1)·M4(2)·M7)는 조당 한 장씩 총 4장을 각각 만들어주세요.

## 3. 힌트 문구 나중에 채워 넣기 (코딩 지식 필요 없음)

`hint-m1.html`, `hint-2f.html`, `hint-m6.html` 세 파일 안에 `여기에 ... 힌트를 적어주세요` 라고 적힌 자리가 있습니다. 수학 문제가 확정되면 그 문장만 바꾸면 됩니다.

1. 깃허브 저장소 화면에서 해당 파일(예: `hint-m1.html`) 클릭.
2. 오른쪽 위 연필 모양(✏️ Edit) 아이콘 클릭.
3. `여기에 M1(조각 찾기) 힌트 문구를 적어주세요...` 부분을 원하는 실제 힌트 문장으로 바꿔 타이핑.
4. 아래로 내려가서 **Commit changes** 클릭.
5. 1분 이내로 실제 사이트에 반영됩니다.

## 4. 영상이 완성되면 끼워 넣기

각 페이지 상단에 이렇게 생긴 부분이 있습니다.

```html
<!-- 나중에 영상 파일을 넣으려면: assets/video/brief.mp4 를 넣고 아래 src를 채우세요 -->
<div class="media-slot empty">
  <video muted playsinline preload="none"></video>
</div>
```

1. 완성된 영상 파일을 `assets/video/` 폴더 안에 올립니다. (깃허브 저장소 → `assets` → `video` 폴더 들어가서 **Add file → Upload files**) 파일 이름은 페이지 이름과 맞추면 헷갈리지 않습니다 (예: `brief.mp4`, `entrance.mp4`, `twist.mp4`, `ending.mp4`).
2. 해당 html 파일을 열어 편집(✏️) 상태에서 위 부분을 아래처럼 두 군데만 고칩니다.

```html
<div class="media-slot">
  <video muted playsinline preload="none" src="assets/video/brief.mp4" autoplay></video>
</div>
```

   - `class="media-slot empty"` → `class="media-slot"` (empty 라는 글자만 지우기)
   - `<video ...>` 태그 안에 `src="assets/video/brief.mp4" autoplay` 추가

3. 영상을 넣으면 화면 전체에 영상이 재생되고, 지금 만들어둔 텍스트/애니메이션 연출은 영상 뒤에 가려집니다. 즉 **영상이 없으면 지금 이 텍스트·애니메이션 버전이 그대로 최종본으로 써도 되고, 영상이 생기면 자동으로 영상 버전으로 업그레이드**되는 구조입니다.

## 5. 배경음악(BGM) 넣기 — html 파일을 열 필요 없이 파일만 올리면 됩니다

**html 코드는 이미 전부 연결해뒀습니다.** 정해진 이름으로 mp3 파일만 올리면 자동으로 소리가 나옵니다.

### 어떤 파일을 몇 개 준비해야 하나요

- 문제·힌트 페이지(m1, m2, m3, m4a, m4b, m5, m6, m7, hint-m1, hint-2f, hint-m6, m1-clear, m4-next, m7-intro) — 이 14개 페이지는 전부 **`bgm.mp3`라는 파일 딱 하나**를 같이 씁니다. 잔잔한 배경음악 한 곡이면 충분합니다.
- 이야기(연출) 페이지 4개는 각각 다른 분위기의 곡을 넣을 수 있게 파일명이 따로입니다.
  - `brief.mp3` (모세의 편지 — 광야, 긴장되는 시작)
  - `entrance.mp3` (성소 입장 — 경건한 분위기)
  - `twist.mp3` (반전 — "철컥" 같은 짧은 효과음 한 번이면 충분, 배경음악 아니어도 됨)
  - `ending.mp3` (엔딩 — 완성의 기쁨, 웅장한 곡)

즉 최소 **`bgm.mp3` 1개**만 있어도 대부분의 화면에 소리가 켜지고, 나머지 4개(brief/entrance/twist/ending)는 있으면 더 좋고 없어도 그 화면만 무음으로 재생됩니다(에러 없이 조용히 넘어갑니다).

### 음악은 어디서 구하나요

제가 직접 음악 파일을 만들어드릴 수는 없어요(오디오 생성 기능이 없습니다). 대신 저작권 걱정 없이 쓸 수 있는 무료 배경음악 사이트를 찾아서 다운로드하시면 됩니다. "무료 배경음악", "royalty free background music", "저작권 없는 배경음악"으로 검색하면 유튜브 오디오 보관함(YouTube Audio Library), Pixabay Music 같은 사이트가 나옵니다. 성막·광야 느낌의 잔잔한 오케스트라/앰비언트 곡을 찾으시면 잘 어울립니다. (다운로드한 파일이 mp3가 아니면, "mp3 변환기"로 검색해 무료 변환 사이트에서 바꾸면 됩니다.)

### 올리는 방법 (영상과 똑같이 클릭만 하면 됩니다)

1. 깃허브 저장소 화면에서 `assets` 폴더 클릭 → `audio`라는 폴더가 없다면 **Add file → Create new file**을 누르고 파일 이름칸에 `audio/dummy.txt`라고 입력하면 `audio` 폴더가 자동으로 만들어집니다 (그 파일은 나중에 지워도 됩니다).
2. `audio` 폴더 안에서 **Add file → Upload files** 클릭.
3. 위에서 정한 이름 그대로(`bgm.mp3`, `brief.mp3` 등) mp3 파일을 끌어다 놓습니다. **이름을 반드시 정확히 맞춰야** 합니다 (대소문자도 그대로).
4. **Commit changes** 클릭 → 1분 이내로 실제 사이트에 반영됩니다.

### 사용법 (조원들 입장에서)

- 문제·힌트 페이지는 화면 왼쪽 위에 작은 🔈 버튼이 있습니다. 그걸 누르면 음악이 켜지고, 다시 누르면 꺼집니다. (휴대폰은 화면을 직접 눌러야만 소리가 나오게 되어 있어서, 자동재생 대신 버튼 방식으로 만들었습니다.)
- "▶ 임무 확인하기" 버튼을 눌러도 그 순간 음악이 같이 켜집니다.
- 이야기(연출) 페이지는 기존처럼 "화면을 터치하면 시작합니다"를 누르는 순간 음악도 함께 시작됩니다.

## 6. 리허설 때 꼭 확인할 것

- 실제로 QR을 찍을 조장 폰(들)으로 각 페이지를 열어, 화면 크기·글자 크기·재생 속도가 괜찮은지 확인해주세요.
- "화면을 터치하면 시작합니다" 문구가 나오는 페이지(모세의 편지·성소입장·반전·엔딩)는 터치해야 다음 장면이 시작됩니다 — 조장에게 "터치 한 번 해야 시작돼요"라고 미리 안내해주세요.
- 각 페이지 오른쪽 위에 작은 ↻ 다시보기 버튼이 있습니다. 영상이 끝난 뒤에 다시 보고 싶을 때 누르면 됩니다.
- 힌트 페이지(hint-m1 / hint-2f / hint-m6)와 문제 페이지(m1 / m2 / m3 / m4a / m4b / m5 / m6 / m7)는 터치 없이 바로 보여지고, 필요하면 화면을 위아래로 스크롤할 수 있습니다.
- 문제 페이지(m1·m2·m3·m4a·m4b·m5·m6·m7)는 이야기 → **"▶ 임무 확인하기"** 버튼 → 문제 순서로 나옵니다. 버튼을 눌러야 실제 문제가 보인다는 걸 조원들에게 미리 알려주세요.
- M3·M4 문제(1)(2)·M7 페이지는 QR에 `?team=조번호`가 없이 열면 조 번호를 고르는 화면이 먼저 나옵니다. 실제 현장 QR에는 반드시 `?team=1`처럼 조 번호가 포함된 주소로 인쇄되어 있는지 리허설 때 꼭 확인해주세요.
- 화면 왼쪽 위 🔈 버튼은 배경음악 켜기/끄기입니다. 아직 mp3를 안 올렸다면 버튼이 흐리게 표시되고 눌러도 반응하지 않습니다(정상입니다).
